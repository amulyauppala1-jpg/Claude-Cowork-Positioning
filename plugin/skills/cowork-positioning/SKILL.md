# Cowork positioning

**This file is a pointer. The system is the repo.**

Read the repo's `README.md` and do what it says. It routes you to the right
files, states the precedence order, lists the non-negotiables, and maps the
request to the skill that builds it. Deliberately none of that is repeated here,
so this file cannot fall out of step with it.

## The repo

```
amulyauppala1-jpg/Claude-Cowork-Positioning
```

Read it whichever way works, in this order:

1. **GitHub connector**, if one is attached to this session.
2. **Direct fetch** of the raw URL. The repo is public, so this needs no
   connector and no account:
   `https://raw.githubusercontent.com/amulyauppala1-jpg/Claude-Cowork-Positioning/main/<path>`
3. **Local folder**, if the repo is open as a workspace.

All three read the same live `main`. Note that raw URLs are cached for about
five minutes, so a change pushed a moment ago may not be visible yet.

## If you cannot reach it, stop

Say you couldn't read the repo and stop there. Do not build from memory, from a
document, from a search result, or from anything earlier in the conversation.

There is nothing in this file to fall back on, on purpose. An asset that looks
right and came from an unknown source is worse than no asset, and it is the
specific failure this system exists to prevent.

## When you deliver

Say which of the three paths you read from, in one line. Live and cached are
different things to whoever relies on the output.
